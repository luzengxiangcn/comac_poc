二、项目概述

本项目旨在采购C919大型客机机身中段和后段的制造服务，包括但不限于：
1. 机身中段（含客舱段）制造，长度约15米，直径约3.96米
2. 机身后段（含尾锥段）制造，长度约8米
3. 机身蒙皮、框架、桁条等结构件的加工与装配
4. 机身段总装、检测与交付
5. 相关技术文档和工艺文件的提供

三、技术要求

3.1 材料要求
1. 蒙皮材料：采用航空级铝合金2024-T3或7075-T6，厚度范围1.2-3.0mm
2. 框架材料：采用航空级铝合金或钛合金，满足AS9100标准
3. 紧固件：符合NAS标准，提供材料证明和检测报告
4. 所有材料需提供完整的追溯性文件，包括批次号、供应商信息等

3.2 制造工艺要求
1. 蒙皮成形：采用数控拉伸成形或滚弯成形，表面粗糙度Ra≤1.6μm
2. 机械加工：采用五轴数控加工中心，加工精度±0.05mm
3. 装配工艺：采用数字化装配技术，装配精度满足图纸要求
4. 焊接工艺：如涉及焊接，需符合AWS D17.1标准，焊工需持证上岗
5. 表面处理：需进行阳极氧化或喷涂处理，满足防腐要求

3.3 质量要求
1. 质量管理体系：供应商需通过AS9100质量管理体系认证
2. 检测要求：所有关键尺寸需100%检测，并提供检测报告
3. 无损检测：关键部位需进行X射线、超声波或渗透检测
4. 交付标准：产品需满足CCAR-25部适航要求
5. 不合格品处理：建立不合格品控制程序，确保不合格品不流入下道工序

3.4 交付要求
1. 交付时间：合同签订后18个月内完成首批交付
2. 交付地点：招标方指定地点（上海浦东）
3. 交付内容：包括产品、技术文档、检测报告、质量证明文件等
4. 包装运输：采用专用工装和包装，确保运输过程中产品不受损
